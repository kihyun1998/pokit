# A hand-written CDP client, not chromiumoxide

pokit speaks CDP through its own small WebSocket client carrying only the methods it uses. `chromiumoxide`'s `Browser::connect` attaches to every page and sends about thirteen commands per page — including `Security.setIgnoreCertificateErrors`, and `Target.closeTarget` if setup stalls 30 s — which changes the state of an app pokit must not disturb; it also ties the build to tokio and a 5.3 MB generated protocol file. Writing the subset by hand keeps every byte sent to the app under pokit's control, including firing `hold`'s key-downs without awaiting replies.
