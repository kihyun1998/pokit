# Pokit brand assets

This pack preserves the supplied Pokit master mark in monochrome form.

- Use `svg/pokit-logo-light.svg` or `png/pokit-logo-light.png` on light backgrounds.
- Use `svg/pokit-logo-dark.svg` or `png/pokit-logo-dark.png` on dark backgrounds.
- Use `readme/pokit-readme-light.png` as the recommended README banner; the dark counterpart is provided for dark pages.
- Social previews are in `social/`; favicons are in `favicon/`.
- `contact-sheet.png` provides a quick visual review of the main treatments.

Do not stretch, crop, recolour, rotate, or otherwise alter the mark. Preserve its clear space and use the supplied light/dark variants for contrast.
